## Overview

This project built a cross-lingual NLP pipeline to generate French named-entity annotations for clinical-trial eligibility criteria. The goal was to expand French medical NLP resources by combining translation, multilingual token classification, and synthetic data generation.

## Approach

- Started from English clinical-trial eligibility criteria.
- Translated the data into French with neural machine translation.
- Fine-tuned XLM-RoBERTa for token classification using Hugging Face Transformers.
- Used the model to generate French NER annotations.
- Evaluated translation and annotation behavior across multilingual benchmarks.

## Results

- Released a 12,423-row synthetic French NER dataset on Hugging Face.
- Demonstrated a practical cross-lingual approach for low-resource medical NLP.
- Produced a reproducible pipeline for synthetic annotation in clinical-trial text.

## Tech Stack

Python, Hugging Face Transformers and Datasets, PyTorch, XLM-RoBERTa, machine translation, Jupyter.
