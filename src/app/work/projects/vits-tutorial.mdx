## Overview

This project documents a reproducible VITS training pipeline for speech synthesis. It supports dataset preparation, text and phoneme processing, model configuration, training, and inference notebooks.

The project is useful as supporting evidence for speech synthesis engineering, model-training workflows, and technical documentation.

## What It Covers

- Dataset formatting and normalization.
- Phoneme handling and alignment preparation.
- VITS model configuration.
- Training workflows for speech synthesis experiments.
- Inference scripts and notebooks for generating audio from text.

## Tech Stack

Python, PyTorch, Hugging Face, Cython, NumPy, Matplotlib, Jupyter.
