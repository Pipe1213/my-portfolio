## Overview

This project developed the first text-to-speech system for Walloon, an under-resourced minority language. The work used a VITS-based architecture adapted to limited speech data and compared different text representations and transfer-learning strategies.

## What I Did

- Built the preprocessing pipeline for Walloon speech data.
- Prepared sentence-level data and text normalization.
- Implemented a rule-based grapheme-to-phoneme workflow for phoneme-based synthesis.
- Trained and compared grapheme-based and phoneme-based configurations.
- Fine-tuned from French-pretrained models and compared against Walloon-only baselines.
- Evaluated generated speech with objective and human perceptual metrics.

## Results

- First Walloon TTS system.
- Best configuration achieved a 4.22/5 MOS.
- First-author publication at SSW 2025.
- Models and demos released publicly.

## Tech Stack

Python, PyTorch, VITS, Hugging Face, speech synthesis, low-resource modeling, perceptual evaluation.
