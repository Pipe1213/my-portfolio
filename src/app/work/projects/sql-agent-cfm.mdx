## Overview

At Capital Fund Management, I built a conversational SQL agent for financial data analysis. The system helped analysts query internal financial databases in natural language by combining retrieval, SQL generation, validation, code execution, and answer synthesis.

The focus was reliability: retrieve the right schema context, generate constrained SQL, validate and execute it, trace the workflow, and produce answers that could be reviewed.

## System Design

- Conversational SQL agent for financial data analysis.
- RAG retrieval pipeline using BM25, dense embeddings, and Reciprocal Rank Fusion.
- Agentic, plan-first workflow for SQL generation, validation, code execution, and answer synthesis.
- LangSmith tracing for debugging and workflow inspection.
- CI/Jenkins checks and test execution to support release readiness.

## Results

- Achieved 87.5% end-to-end accuracy on a 48-question internal benchmark.
- Achieved 95% top-k retrieval accuracy with BM25, dense embeddings, and Reciprocal Rank Fusion.
- Deployed the system as an analyst-facing tool.

## What I Worked On

- Designed and implemented the retrieval and SQL-agent workflow.
- Built validation, execution, and answer-synthesis steps.
- Debugged model and tool failures using traces and benchmark results.
- Supported release readiness with testing, debugging, LangSmith tracing, and CI/Jenkins checks.

## Tech Stack

Python, SQL, Oracle, LangChain, LangGraph, LangSmith, ChromaDB, BM25, Reciprocal Rank Fusion, Streamlit, CI/Jenkins.
