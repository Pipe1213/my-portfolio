## Overview

This project implemented a Structure-from-Motion pipeline for reconstructing sparse 3D scenes from multiple 2D images. It is included as a lower-priority portfolio project because it shows computer-vision and engineering fundamentals, even though the current job-search focus is applied AI, NLP, and LLM systems.

## Approach

- Detected image features with SIFT.
- Matched features across views using FLANN.
- Estimated camera geometry with RANSAC and PnP.
- Triangulated 3D points from matched correspondences.
- Refined the reconstruction through bundle adjustment.
- Visualized camera positions and reconstructed point clouds.

## Tech Stack

Python, OpenCV, NumPy, Matplotlib, SIFT, FLANN, RANSAC, PnP, bundle adjustment.
