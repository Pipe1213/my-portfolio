Code on GitHub

What it does

You ask a question in plain English. AskData writes a read-only SQL query, runs it on PostgreSQL and answers with a sentence, a table and, when the result suits one, a bar or line chart.

How a question is answered

  • Retrieve the relevant schema context.
  • Plan and generate the SQL.
  • Validate it as read-only, then execute it.
  • Repair the query once if it fails.
  • Summarise the result and suggest a chart.

Testing and next steps

The backend has 13 test files, from SQL validation to the query pipeline. A benchmark script with three sets of 10 questions is ready; its results will go here, with the limits found, when the run is done.
