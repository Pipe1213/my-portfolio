Selected work

2025, Capital Fund Management, Paris

An LLM agent that answers financial data questions in SQL

Seven tools, an internal Oracle database, and a 48-question benchmark I designed to measure it. Accuracy rose from 83% to 87.5%, and giving each task a suitable model made each query about 20× cheaper than o3.

Read the case studyInternship report (PDF)

2024, LISN, CNRS and Université Paris-Saclay

The first speech synthesis system for Walloon

VITS models trained on 18 to 156 minutes of speech. With only 18 minutes of the female voice, fine-tuning from French raised the listener score from 3.38 to 4.10 out of 5. First author, oral presentation at SSW 2025.

Read the case studyPaperTry the demo

2026, personal project

AskData: plain-English analytics on PostgreSQL

A text-to-SQL web app for PostgreSQL, built with FastAPI and Next.js. Before any SQL is written, a triage step routes each question to answer, clarify or decline. On 32 held-out test questions it gave 1 wrong answer, at under a cent per question.
